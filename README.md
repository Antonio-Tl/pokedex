# Pokedex

Lokale React/Vite-Anwendung fuer eine Pokedex-UI.

## Voraussetzungen

- Node.js 18+ (empfohlen: aktuelle LTS)
- npm

## Lokal starten

1. Abhaengigkeiten installieren:
   npm install
2. Entwicklungsserver starten:
   npm run dev
3. Im Browser oeffnen:
   http://localhost:5173

## NPM-Skripte

- npm run dev: startet den Vite-Dev-Server
- npm run build: erstellt ein Produktions-Build
- npm run preview: startet die Build-Vorschau
- npm run lint: prueft den Code mit ESLint
- npm run lint:fix: versucht Lint-Probleme automatisch zu beheben

## Hinweise

- Es wird keine zusaetzliche .env.local zum lokalen Start benoetigt.
